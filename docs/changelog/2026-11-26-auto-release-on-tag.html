Auto release on tag

Specs

Pushing a v* tag should publish the GitHub Release (DMGs, updater archives, latest.json) without a manual publish step.

Actions

  • .github/workflows/release.yml: releaseDraft: false, header comment updated.
  • Updated docs/claude/deployment.md, README.md, CHANGELOG.md.

Tradeoffs

Publishing directly removes the review step, and a failed matrix job leaves a partial public release (delete the release and tag, then retry). Chosen for a hands-off flow; releaseDraft: true restores review.
