Per-profile transfer settings and Import from AWS CLI

Specs

Roadmap step 4, settings part only: optional profile fields multipart_threshold, multipart_chunksize, max_concurrent_requests, addressing_style with old vaults still loading; AWS-CLI-style size parsing; rules (chunk size ≥ 5 MiB, threshold ≥ chunk size, concurrency 1..256, style path/virtual/auto) validated by Rust and mirrored in TypeScript; addressing_style effective in the S3 client; a collapsed "Transfer settings" form section; an "Import from AWS CLI" button reading only non-secret keys from the AWS config file on click. Multipart transfers themselves are out of scope.

Actions

  • New transfer_settings.rs: parse_size, validate_transfer, effective_transfer_settings, AddressingStyle, flattened TransferFields in Profile, ProfileInput, ProfileSummary.
  • New aws_config.rs and commands aws_config_list_profiles, aws_config_read_profile (registered in lib.rs).
  • profile_rules.rs calls validate_transfer; s3.rs uses the addressing style; validate_profile.ts, aws_import_api.ts, profile_form.tsx, styles.css updated; 27 shared table cases added.
  • Tests: Rust 134 pass (size table, defaults, old-shape vault JSON, rules, parser, URL per style); vitest 258 pass; npm run build and cargo check clean.

Measured: test and build outputs above; Chromium screenshots against a mocked __TAURI_INTERNALS__ (light and dark). Inferred, not exercised: behaviour against a real MinIO, a real ~/.aws/config, the Tauri window and WebKit; virtual-hosted URL shape for a host without a DNS wildcard (only the request URL was captured).

Tradeoffs

  • Fields stored as normalized strings, not bytes: the form shows what was typed and a bad import stays visible; cost: parse at use time (done once, in effective_transfer_settings).
  • Decimals (1.5MB) rejected, like the AWS CLI; suffixes KB..TB only, KiB rejected.
  • When threshold is unset and chunk size exceeds the default 8 MiB threshold the error lands on the chunk size field (the one the user filled).
  • auto behaves like virtual (SDK default); the SDK itself falls back to path style for IP hosts.
  • Import is a line-based INI reader, not a full AWS config parser: no inline comments, no include, no source_profile.
  • No upper bound on chunk size (S3 max 5 GiB) since the spec lists none.
