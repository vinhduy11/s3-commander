Go to path and remember the last folder

Specs

  • Owner request: (1) move a panel straight to a directory by typing or pasting its path; (2) remember the last folder accessed and restore it at the next launch.
  • Editable path field in each panel header (click or Cmd/Ctrl+L; Enter goes, Esc and blur cancel; text selected on focus; recents dropdown of 20 per panel kind). One pure parser parseLocation(input, current): Local (absolute, ~, relative, file://, quotes, trailing slash) and Server (s3://bucket/prefix/, /prefix/, relative), textual . and .. never above the root, kind switches with a notice.
  • A target that cannot be listed keeps the old location and shows a readable error under the field. Navigation uses the existing loader.
  • Persist (guarded, versioned, validated): Local path per side, server bucket and prefix per profile, active panel; restore at launch and on profile switch with nearest-parent fallback; first run unchanged. Names only; documented in safety.md.
  • Out of scope: bookmarks, file watchers, operations, selection, sorting, updater, vault, settings.

Actions

  • Rust: local::home_dir_from / home_dir and the command home_dir (error string when HOME is missing, empty or relative; never panics). 2 tests.
  • New frontend files in src/browse/: parse_location.ts, go_to_flow.ts, location_memory.ts, last_location.ts, path_field.tsx and their tests (parse table, memory, flow, restore and save, field behaviour).
  • Edits to shared files, small and additive: panel_loader.ts (openLocation, restoreLocation, fallback option reusing the reload parent fallback), navigation.ts (sameSource moved here), browse_api.ts (homeDir), file_panel.tsx (PathField, Cmd/Ctrl+L), browser_screen.tsx (restore and save wiring), styles.css, lib.rs (command registration).
  • Docs: README structure, CHANGELOG, architect (syntax table, keys, restore order), safety, rule.

Tradeoffs

  • Failure handling by snapshot: after a failed source switch the previous panel state is put back instead of adding a "try listing first" API to the loader; simple, but a switch briefly shows the empty new source while loading.
  • Save by polling the store: a debounced subscriber reads settled panels (not loading, with a source) rather than hooking every navigation call; one place, but a navigation that lasts longer than the 400 ms debounce is saved when it finishes.
  • Cmd/Ctrl+L is panel-level (the focused panel), not a window listener like Cmd/Ctrl+R; when focus is on the page body it does nothing until a panel is clicked.
  • Left panel remembered as server with no usable bucket opens Local home (also after a profile switch, where it used to stay empty); chosen over a blank panel.
  • Recents shared per kind (not per profile or per panel), as requested; server recents of another profile may name a bucket that is missing, which gives the inline error.
  • Remembered names stay in local storage after Lock (only names, documented), instead of clearing on Lock which would defeat restore at the next launch.

Inferred, not exercised
