Conflict dialog: hide "all" buttons on the last conflict

Specs

The owner saw "Already exists (1 of 1)" with Overwrite all, Skip all and Keep both all, which are pointless when only one conflict is left.

Actions

  • Measured: new src/ops/ops_dialogs.test.tsx (3 tests). Before the fix 2 failed (single conflict, last of several) and 1 passed (conflicts still to come keep the "all" buttons).
  • ConflictButtons in src/ops/ops_dialogs.tsx takes hasMore (index < conflicts.length - 1); without more conflicts the second row is dropped and Cancel joins the first row.
  • Measured: npm test 148 passed, npm run build ok.

Tradeoffs

The "all" buttons stay on every conflict except the last, so the flow is unchanged for several conflicts. Alternative considered: hide them only when the total is 1; rejected because on the last of several conflicts they repeat the plain choices too.

Not exercised: the real Tauri window.
