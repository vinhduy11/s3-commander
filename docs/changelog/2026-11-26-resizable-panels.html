Resizable panels

Specs

Owner request: the two file panels can be resized. A vertical splitter between them: drag to resize, 240 px minimum per panel, ratio kept on window resize, remembered across view switches and restarts, keyboard and screen-reader operable, hidden in the narrow single-column layout, never a drop target. Out of scope: column widths, vertical resize, operation logic.

Actions

  • src/browse/panel_split.ts: pure clamp, keyboard step, pointer-to-ratio, guarded localStorage load and save.
  • src/browse/panel_splitter.tsx: the separator (pointer capture, ArrowLeft/Right 16 px, Shift 64 px, Home and double-click reset, aria-value*).
  • src/browse/browse_store.ts: splitRatio and setSplitRatio (layout slice).
  • src/screens/browser_screen.tsx and src/styles.css: 3-column grid, splitter styles, narrow-layout reset, @container rule hiding Date under 420 px.
  • Tests: panel_split.test.ts, panel_splitter.test.tsx (keyboard, drag, remount, persistence failures, narrow CSS, hit-testing after a ratio change, splitter not a drop target). Red run first (modules missing), then green: 318 tests.
  • Separate commit: Vite dev watcher ignores .claude/ and src-tauri/target/.
  • Checked in Chromium with a mocked Tauri bridge: real mouse drag to about 30/70 and to the minimum, keyboard focus, light and dark, narrow window.

Tradeoffs

  • Ratio, not pixels: panels scale with the window; the 240 px minimum is enforced by the grid (minmax(240px, Nfr)) so no resize observer is needed; JS clamps only during drag and keys.
  • Splitter outside both panels: drop hit-testing already reads live DOM geometry and ignores anything outside [data-panel], so no code change there.
  • Panels intercept Tab to switch panel, so the splitter is reachable by click first, then keys; a global shortcut was not added.
  • Narrow panels hide the Date column via a container query, otherwise Name collapsed to nothing at the minimum width.
  • The watcher ignore also silences file watching when Vite itself runs from inside a worktree under .claude/; restart it there to pick up changes.
  • Column-width resizing hook: the .row grid template is the single place; a future per-column variable set could follow the same store-and-persist pattern. Not built.
