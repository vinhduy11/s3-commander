Copy presigned URL in the empty-space right-click menu

Specs

The owner marked several files in a server panel, right-clicked on the empty space of the panel and found no presign entry. Measured in the code: the entry existed only in the row menu (rowItems), by the step 3d design, and an existing test asserted its absence in the empty-space menu.

Actions

  • Measured: the old expectation was changed and three tests added in src/browse/context_menu.test.ts; before the fix 3 failed, 33 passed.
  • emptyPresignItems in src/browse/context_menu.ts adds "Copy presigned URL" (F9) to the empty-space menu of a server panel; it is enabled only when rows are marked (the cursor row alone does not count) and calls the same startPresign flow, which presigns the marked rows.
  • Measured: npm test 597 passed, npm run build ok.

Tradeoffs

Disabled rather than hidden when nothing is marked, so the entry stays discoverable. Local panels still have no entry (there is no object to presign). Other marked-set actions (copy, move, delete) are not added to the empty-space menu; that is a possible follow-up.

Not exercised: the real Tauri window.
