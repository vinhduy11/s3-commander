Right-click context menu (step 3c)

Specs

Right-click menu on rows and empty panel space: Open, Upload/Download/Copy, Move, Rename, Delete, New folder. Unmarked row selects only itself, marked row acts on all marks, empty space shows New folder only. Same flows as the F-keys, keyboard and a11y, tokens-only styling, no Rust changes.

Actions

  • New src/browse/context_menu.ts (store, item list, selection rules, clampMenuPosition) and context_menu_view.tsx (role=menu surface).
  • file_panel.tsx: contextmenu handlers, Shift+F10 / ContextMenu key; panel_loader.ts: openRowAt shared by Enter and Open; browser_screen.tsx mounts the menu.
  • Styles in styles.css (existing tokens only); vite.config.ts excludes .claude/** from tests.
  • Tests: context_menu.test.ts, context_menu.test.tsx; full suite and build green.

Tradeoffs

  • Handlers take the right-clicked side explicitly instead of relying on the active panel; the flows already accepted a side.
  • Items are snapshotted when the menu opens so they cannot change under the pointer.
  • View, Edit and presigned URL are omitted until steps 5 and 3d; the item list makes them a one-entry addition.
  • Verified in jsdom and Chromium with a mocked Tauri bridge; not in a real WebKit window.
