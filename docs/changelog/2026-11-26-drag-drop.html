Drag and drop (roadmap step 3b)

Specs

  • In-app drag between and within the two panels: plain drop copies, Shift moves, folder row targets that folder, same panel only onto a folder row (move).
  • Refuse folder onto itself or its child, onto "..", and onto a panel without a source; never drag "..".
  • Ghost, target highlight, copy/move cue, not-allowed cue; Esc cancels; auto-scroll; click, double-click, mark and context menu unchanged.
  • Drop from the OS file manager onto a server panel with real paths; same planner and dialogs as F5.

Actions

  • New src/browse/drag_drop_logic.ts, drop_locations.ts, drag_drop.ts, drag_drop_view.tsx, os_drop.ts with vitest suites.
  • ops_flow.ts: startTransferOf(operation, mode) extracted from startTransfer (same dialogs); a same-panel move refreshes the panel once.
  • file_panel.tsx: data attributes, panelDragProps, useDropHighlight (small additive changes); browser_screen.tsx: DragLayer and the OS-drop listener; styles.css: separate drag block.
  • Rust: command local_stat_paths (local::stat_paths, tempdir tests). Planner commands are unchanged. tauri.conf.json: dragDropEnabled: true (already the default).

Tradeoffs

  • Pointer events over HTML5 DnD: HTML5 DnD is unreliable in the Tauri webview on WebKit/WebKitGTK and conflicts with Tauri's native handler. Cost: ghost, hit-testing, auto-scroll and Esc are implemented by hand.
  • One parent folder per OS drop: the planner takes items relative to one source directory; a mixed-parent drop is refused with a message instead of extending the planner. A Finder multi-selection is always one folder.
  • OS drops always copy (the event carries no modifier keys). Dragging out of the app is not supported.
  • Not verified without a real window: the real Tauri window, an actual Finder/Files drop and the physical-to-CSS position mapping on a real Retina display, WebKit/WebKitGTK rendering and pointer behavior, a real server, real keyboard and mouse use. Verified: vitest, cargo tests, and Chromium mock screenshots with a mocked __TAURI_INTERNALS__ and real Playwright mouse drags.
