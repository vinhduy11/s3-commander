UI redesign: Modern direction

Specs

  • Redo the visual UI of the Tauri MinIO file manager (owner: current UI is "ugly"). Visual and layout only: no behavior, store, Rust, command or keyboard changes, no new features.
  • Direction chosen by the owner: Modern (Finder / Linear / Raycast spirit): soft surfaces, subtle borders and shadows, rounded corners, refined type, crisp icons, restrained transitions, light and dark.
  • Kept: dual-pane, keyboard-first, dense file rows, offline only (no CDN or web fonts), WebKit-safe CSS, existing tests green.

Actions

  • New src/tokens.css (palette, type scale, 4px spacing grid, radius, motion; light and dark via prefers-color-scheme) and src/styles.css (all components); removed the Vite template src/App.css.
  • New src/icons.tsx: inline SVG icons (folder, parent, lock, key, server, disk, and file glyphs tinted by type: image, archive, code, media, document, generic).
  • Markup-only changes (class names, wrappers, icons) in master_key_screen.tsx (centered card with key mark, primary button, error alert), profiles_screen.tsx (profile list with actions, grid form, empty state, notice and alert), browser_screen.tsx (brand mark, Lock icon, F-key labels split into key and name), file_panel.tsx (source tag with icon, entry icons instead of [brackets], loading spinner in the footer, explicit boolean props).
  • Active panel: accent border plus soft shadow; cursor row: accent-soft fill and outline in the active panel, neutral fill in the inactive one; marked rows: orange text and icon. Fixed-width WebKit scrollbar keeps the column header aligned with rows.
  • Tests: none changed (no test queries the markup); build and 16 vitest tests pass. Rust untouched.
  • Visual check: Vite dev server with a throwaway in-page mock of the Tauri commands (kept outside the repo) and Playwright screenshots in light and dark at 1280x800 and 900x600.

Tradeoffs

  • Plain CSS with custom properties instead of a UI framework: zero dependencies, theme is just token overrides.
  • System font stack instead of a bundled font: no extra bytes and fully offline, at the cost of slightly different type per OS.
  • Hand-drawn inline SVG icons instead of an icon library: no dependency, but a limited glyph set (six file kinds).
  • Single indigo accent plus functional colors (orange marks, red errors, green ok) keeps the dense list calm; file-type tints are small and only on icons.
  • Rows stay 22px (virtual list constant), so the modern feel comes from surfaces, radius and icons, not from bigger rows.
  • Name column shows icon and plain name instead of [dir] brackets (text change in rendering only).
